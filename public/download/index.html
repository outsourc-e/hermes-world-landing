System requirements

NetworkInternet connection required. The preview connects to the HermesWorld cloud server.
StorageAt least 5 GB free for download, extraction, and logs.
Memory8 GB RAM recommended. Close heavy apps for best first-load behavior.
GraphicsDiscrete GPU preferred, modern integrated GPUs supported for preview testing.

Mac install

  1. Download HermesWorld-Mac-v1.0.7.pkg.
  2. Double-click the installer.
  3. Click Continue, then Install. Enter your Mac password if asked.
  4. HermesWorld will auto-launch when the installer finishes.
  5. Sign in, choose a character, and enter the world.

Windows install

  1. Download HermesWorld-Setup-v1.0.1.exe.
  2. Double-click the installer.
  3. If SmartScreen appears, choose More info → Run anyway. The preview is not code-signed yet.
  4. Click through the wizard. The installer adds a Start Menu shortcut and desktop icon with the cloud server baked in.
  5. Launch HermesWorld, sign in, choose a character, and enter the world.
Alpha status & what is next: these are Alpha builds — expect rough edges, especially in the starting zone. The next build ships a proper Training Grounds spawn (working trainers, dummies, harvest nodes, and combat flow) along with an updated WebGL build at /play/web/ for instant browser play.

Developer certificates are processing (Apple Developer Program for macOS, Azure Trusted Signing for Windows). Once approved, signed builds will eliminate the Gatekeeper warning on Mac and SmartScreen warning on Windows. Until then, the bypass steps above work cleanly.
