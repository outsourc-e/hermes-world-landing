System requirements

NetworkInternet connection required. The preview connects to the HermesWorld cloud server.
StorageAt least 5 GB free for download, extraction, and logs.
Memory8 GB RAM recommended. Close heavy apps for best first-load behavior.
GraphicsDiscrete GPU preferred, modern integrated GPUs supported for preview testing.

Mac install

  1. Download HermesWorld-Mac-v1.0.zip.
  2. Double-click the zip and keep the extracted folder intact. Do not drag only the .command file somewhere else.
  3. Open the folder and right-click HermesWorld-Manual.command, then choose Open.
  4. If macOS asks, approve the unsigned preview app. The launcher removes quarantine and starts the cloud-connected client.
  5. Sign in, choose a character, and enter the world.

Windows install

  1. Download HermesWorld-Windows-v1.0.zip.
  2. Right-click the zip and choose Extract All. Do not run the game from inside the compressed zip view.
  3. Open the extracted folder and run the included cloud launcher.
  4. If SmartScreen appears, choose More info → Run anyway.
  5. Sign in, choose a character, and enter the world.
Installer roadmap: the current preview uses zip packages so testers can get in quickly. Native packaging is next: a Mac .dmg with drag-to-Applications flow and a Windows installer with Start menu / desktop shortcuts and the cloud server flags baked in. That will prevent the “launcher moved away from app” error some Mac testers hit.
